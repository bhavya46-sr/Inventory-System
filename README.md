# Inventory-System
Inventory Management System

A web-based Inventory Management System developed using HTML, CSS, and JavaScript. This application allows users to manage products efficiently by adding, editing, deleting, and searching inventory items. The system stores data using browser Local Storage and provides a dashboard with inventory statistics, low-stock monitoring, category analysis, and CSV export functionality.

Key Features

- Product Management (Add, Edit, Delete)
- Search and Filter Products
- Low Stock Alerts
- Dashboard Analytics
- Category-wise Inventory Summary
- CSV Export
- Local Storage Data Persistence
- Responsive User Interface

Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API
